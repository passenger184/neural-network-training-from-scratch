# Neural Network Training From Scratch

A deep neural network implemented entirely from scratch using NumPy.

## Features

- Multi-layer neural network
- Forward propagation
- ReLU activation
- Softmax output
- Cross-entropy loss
- Backpropagation
- Gradient descent weight updates
- Training loop with accuracy tracking

## Architecture

Input Layer (5)
→ Hidden Layer 1 (6)
→ Hidden Layer 2 (8)
→ Hidden Layer 3 (8)
→ Output Layer (3)

## Technologies

- Python
- NumPy

## Learning Goals

This project was built to understand the mathematical foundations of deep learning without using frameworks like PyTorch or TensorFlow.
